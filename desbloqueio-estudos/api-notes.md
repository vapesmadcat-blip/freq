# Notas de integração

A API ENEM (https://enem.dev/) é um projeto comunitário open-source, sem afiliação ao INEP/MEC, com mais de 2.700 questões dos anos de 2009 a 2023. A documentação pública informa que os dados podem ser usados sem atribuição obrigatória, respeitando a licença GNU GPL-2.0. A implementação deve tratar a API como fonte remota opcional, exibir fallback local quando houver erro ou ausência de rede e evitar prometer cobertura de concursos, pois a fonte verificada é específica do ENEM.

Referências: https://enem.dev/ e https://docs.enem.dev/introduction
